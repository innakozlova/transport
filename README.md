# ИИ-Предиктор задержек наземного пассажирского транспорта Москвы

Комплексное микросервисное решение для раннего прогнозирования изменений в графике движения транспорта **за 10–15 минут** до фактического наступления задержки. Система анализирует потоковые телематические данные (формат NDTP) и накладывает их на эталонное расписания.

**Лучший скор на платформе:** `0.66` (Метрика MAE оптимизирована алгоритмами градиентного бустинга).

---

## Архитектура системы

Проект разделен на независимые модули, изолированные в Docker-контейнерах:
1. **ML-ядро (`ml_service.py`)** — изолированный микросервис инференса на базе FastAPI. Принимает телеметрию, извлекает пространственно-временные фичи и мгновенно рассчитывает точечный прогноз задержки в секундах.
2. **Backend & BI-дашборд (`backend_service.py`)** — оркестратор данных. Отвечает за логику связи, реализует веб-панель диспетчера и обеспечивает отказоустойчивость контура.

---

## Особенности производительности и фичи

* **Низкий Latency инференса:** Время обработки одной прогнозной точки моделью CatBoost составляет менее **5 мс**, что полностью обеспечивает честный Real-time режим для сотен ТС одновременно.
* **Временной Feature Engineering:** Пайплайн предобработки автоматически извлекает циклические признаки часа суток (`hour` для детекции утренних/вечерних часов пик) и дня недели (`day_of_week` для учета паттернов будни/выходные), превосходя наивный baseline.
* **Отказоустойчивость (Graceful Degradation):** При обрыве связи с потоком эмулятора телеметрии NDTP бэкенд мгновенно и бесшовно переключается на автономный режим генерации прогнозов по последнему известному состоянию задержки (`cur_dev_s`), сохраняя стабильность системы без падения сервисов.

## Инструкция по развертыванию для жюри

### 1. Запуск предиктивного контура и Дашборда
Развертывание всей экосистемы из корня папки `src` одной командой:
```bash
docker-compose up --build
```
После сборки диспетчерский BI-дашборд будет доступен в браузере по адресу: **`http://localhost:8000`** (данные дашборда обновляются автоматически каждые 3 секунды).

### 2. Запуск потокового эмулятора телеметрии (NDTP)
Для генерации живого потока навигационных ячеек `G6CellNav00` запустите образ эмулятора из раздачи:
```bash
docker load -i ndtp-telemetry-emulator.tar
docker run --rm -p 18080:18080 --add-host=host.docker.internal:host-gateway --name ndtp-emu ndtp-telemetry-emulator:1.0
```

## 📖 Документация API

Благодаря использованию FastAPI, спецификация веб-служб и интерактивная документация **OpenAPI / Swagger** генерируются автоматически при запуске контейнеров:

* **Интерактивный Swagger ML-ядра:** `http://localhost:8001/docs`
* **Спецификация OpenAPI бэкенда:** `http://localhost:8000/docs`

Жюри может протестировать ручки инференса и форматы отправляемых JSON-пакетов прямо из окна браузера.
